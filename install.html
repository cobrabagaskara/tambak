📋 Panduan Instalasi

1 Instal Tampermonkey

Download dan instal ekstensi Tampermonkey untuk browser Anda:

Chrome Firefox Edge
Catatan: Tampermonkey WAJIB diinstal terlebih dahulu.
2 Instal Loader Script

Klik tombol di bawah untuk instalasi otomatis:

Atau klik link: pkmkedawung-loader.user.js

Instalasi otomatis: Klik tombol, lalu klik "Install" di popup Tampermonkey.
3 Verifikasi Instalasi

Setelah instalasi berhasil:

  1. Buka cirebon.epuskesmas.id
  2. Cari tombol ⚙️ di pojok kanan bawah
  3. Klik tombol untuk membuka dashboard
  4. Module akan otomatis terdeteksi dan siap digunakan
4 Gunakan Module

Module tersedia berdasarkan halaman yang Anda buka:

📊

❓ Pertanyaan Umum

Apakah aman menggunakan script ini? ▼
Ya, 100% aman. Script bersifat open-source, hanya berjalan di browser Anda, dan tidak mengirim data ke server luar. Semua kode bisa diperiksa di GitHub.
Bagaimana cara update script? ▼
Update otomatis melalui Tampermonkey. Anda juga bisa klik "Check Updates" di dashboard untuk update manual.
Apakah bisa digunakan di browser lain? ▼
Bisa di semua browser yang support Tampermonkey: Chrome, Firefox, Edge, Opera, dll. Install Tampermonkey terlebih dahulu.
Bagaimana cara menambahkan module baru? ▼
Module baru otomatis muncul di dashboard setelah developer mengupload ke sistem. Tidak perlu instal ulang.
