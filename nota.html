INFO CETAK KE PRINTER THERMAL

Untuk cetak ke printer thermal Bluetooth:

Web browser biasa tidak bisa langsung print ke printer thermal. Solusi:

  • Gunakan aplikasi khusus seperti "PrintBot" atau "PrintShare"
  • Export struk sebagai PDF lalu print dari aplikasi printer
  • Share/Send struk ke aplikasi printer thermal
  • Setting paper width: 80mm untuk printer thermal

Tombol "Ekspor Struk" akan menghasilkan file JSON yang bisa dikonversi ke PDF.
