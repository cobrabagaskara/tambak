🚀 GitHub Auto Sync

Status: Tidak terhubung ke GitHub

Untuk auto-sync ke GitHub, Anda perlu:

  1. Buat Personal Access Token di GitHub
  2. Token membutuhkan scope: repo dan workflow
  3. Tempel token di bawah ini
Repo Target:
Contoh: username/repo (tanpa https://github.com/)
Cara mendapatkan GitHub Token
  1. Login ke GitHub → Settings → Developer settings
  2. Personal access tokens → Tokens (classic)
  3. Generate new token (classic)
  4. Berikan nama: "TM Converter Sync"
  5. Pilih scopes: repo (full control), workflow
  6. Generate token → Copy token
  7. Tempel token di atas
